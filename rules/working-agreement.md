# How to work

## Keep going

- Do not stop between steps to report and wait. Finish the chain, report once.
- Ask only where the answer changes what gets built and no sane default exists.
  Otherwise state the assumption and continue.
- Prefer the smallest change to what exists over a new mechanism.

## Evidence

- Measure before concluding, and name the environment, window and command.
- A tool's output describes the lookup that produced it: empty, zero, and a
  complete-looking result set are instrument properties until confirmed in-band.
  A captured log is not complete until its terminal marker is present.
- Reject a root cause on scope, timing and error identity together. One axis is a
  coincidence.
- Retract where the claim was made, with the corrected number.

## Cost

- Scope a probe before widening it. A slow probe is usually the wrong predicate,
  not too small a window.
- Use the cheapest model that can do the step.
- Watch what a change costs to run repeatedly: CI time, test count, context.

## Finish the loop

- Merged is not shipped. Confirm the image or config is running where it should
  be, then measure the effect.
- Fix the class, not the instance: enumerate the siblings from the built artifact
  and push the fix upstream.
- Before compacting or clearing, write state into a durable tracker: settled,
  open, next.
